# 📝 To-Do List App with Database Authentication

A simple and efficient To-Do List application with user authentication, built using **MongoDB, Express, React, and Node.js (MERN Stack)**.

## 🚀 Live Demo
🔗 [Live Site](https://todo-list-campus.netlify.app/)

## 📦 Features
✅ User authentication (Sign Up & Login)  
✅ Add, update, and delete tasks  
✅ Store tasks securely in MongoDB  
✅ Responsive and user-friendly UI  

## 🛠 Tech Stack
- **Frontend**: React, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **State Management**: Redux
